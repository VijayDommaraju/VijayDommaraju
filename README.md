

## 👋 Welcome Spartans

I'm **Vijay Dommaraju**, a **Java Backend Engineer** focused on building secure, scalable, maintainable and production-ready backend systems.

My core stack is **Java, Spring Boot, Spring Security, JPA/Hibernate and MySQL**, with a growing focus on **Redis, Kafka, Docker, microservices, distributed systems, performance and system design**.

I enjoy going beyond individual endpoints — understanding **architecture, transactions, concurrency, caching, messaging, reliability, observability and deployment**.

## 🚀 Expertise

- ⚙️ **Backend Engineering** — Building secure, scalable and maintainable REST APIs using Java and Spring Boot.

- 🔐 **Security & Authorization** — Designing authentication, JWT-based security, role-based access control and secure API architectures.

- 🗄️ **Database Engineering** — Designing relational schemas, JPA/Hibernate mappings, complex SQL queries, indexing, transactions and query optimization.

- 🏗️ **System Design** — Designing modular, scalable and reliable backend architectures with clear separation of responsibilities.

- 🌐 **Distributed Systems** — Working with microservices, asynchronous communication, messaging, caching and service-to-service interactions.

- ⚡ **Performance Engineering** — Optimizing database queries, API performance, caching strategies, concurrency and resource utilization.

- 📨 **Messaging & Event-Driven Systems** — Working with Kafka and RabbitMQ for asynchronous processing and event-driven architectures.

- 🚀 **DevOps & Deployment** — Working with Docker, Kubernetes, Jenkins, GitHub Actions and deployment workflows.

- 📊 **Observability & Reliability** — Understanding logging, monitoring, metrics, Grafana, failure handling and production system reliability.

- 🧠 **Engineering Mindset** — Thinking beyond individual features by understanding architecture, data flow, scalability, failure scenarios and long-term maintainability.
